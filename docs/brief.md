## Principles

The portfolio itself is a work sample — it should demonstrate the same UX thinking it claims.

1. Visual effects support storytelling. They never lead it.
2. Usability, accessibility, responsiveness, and performance outrank decorative animation.
3. Three.js is used selectively, only where it earns its cost in storytelling or interaction value.
4. The simplest implementation that accurately represents the intended design wins.

## Evidence Rules

These apply to every document in this repository and to any AI assistance used on it.

1. Do not invent metrics, research findings, user feedback, business outcomes, or decisions.
2. Mark anything unconfirmed as `REQUIRES VERIFICATION` rather than guessing.
3. Archived or exploratory work is never a final reference.
4. Read the relevant project doc before using project material.
5. Flag ambiguity instead of resolving it silently.
